Custom system prompts — curating the experience

The System prompt is the “director’s note” at the very top of what the model sees. It sets the frame — tone, format, pacing — that everything else operates inside. It is not the whole bartender: identity and lore are injected separately, so you don’t need to restate them here.

How the prompt is assembled

  1. System prompt (yours, or the built-in assistant prompt)
  2. About {{user}} — the persona
  3. lorebook entries → the character block (description, personality, background) → example dialogue
  4. memory (pinned facts, standing orders, facts, where things stand) and today’s date
  5. …the chat history…
  6. Post-history instructions — a second system message after the history
  7. the reply-format reminder, then your latest message quoted back

Two slots, different jobs

  • System prompt (top): the frame. Read first, but a long chat can drift from it.
  • Post-history instructions (bottom): strongest adherence. Put the one or two hard rules the model keeps forgetting here (e.g. “Always answer in British English”).

What you can curate

  • Length / pacing — “reply in 2–4 sentences”, “lead with the answer”.
  • Tone — wry, warm, clipped, formal, playful.
  • Address — “call me Captain”. (Or just say it in a chat: it becomes a standing order.)
  • Anti-patterns — “don’t repeat earlier phrasing”, “don’t end by offering more help”.

Everything is spoken

Every word of a reply is read aloud, so the built-in prompt asks for plain spoken prose: no markdown, tables or lists, numbers as words. Anything that slips through is cleaned before it is spoken, but a custom prompt should keep the rule.

Gotcha

Your custom prompt fully replaces the built-in one — which is where the guardrails live (one reply, no invented scene, speak for the ear, don’t speak for {{user}}, no repetition, never mention being an AI). If you write a bare prompt, bake those in or keep them in Post-history instructions.

Examples — copy & paste into a card’s System prompt

Witty assistant (Jarvis-style) 
You are {{char}}, in direct conversation with {{user}} — no scene or setting to narrate; never invent surroundings or events. Voice: dry, precise, quietly witty, unflappably competent. Everything you say is spoken aloud: plain sentences, no markdown or lists, numbers as words. Reply in 1–4 sentences and lead with the answer. Write only {{char}}'s next reply; never speak or act for {{user}}; don't repeat earlier phrasing; stay in character and never mention being an AI.
Warm bartender 
You are {{char}}, the bartender {{user}} talks to at the end of the day. Friendly, unhurried, a little teasing; you remember what {{user}} tells you. No scene or setting — just what you say out loud, in plain spoken sentences. 1–3 sentences. Never speak for {{user}}; stay in character.
