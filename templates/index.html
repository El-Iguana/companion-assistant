            Help & guide

            Custom system prompts — curating the experience

            The System prompt is the “director’s note” at the very top of what the model sees. It sets the frame — tone, format, pacing, boundaries — that everything else operates inside. It is not the whole character: identity and lore are injected separately, so you don’t need to restate them here.

            How the prompt is assembled

            1. System prompt (yours, or the Chat mode default)
            2. About {{user}} — the persona
            3. the relationship descriptor (stage, intimacy, mood)
            4. lorebook entries → the character block (description, personality, scenario) → example dialogue
            5. memory (pinned facts + running summary)
            6. …the chat history…
            7. Post-history instructions — a second system message after the history

            Two slots, different jobs

            • System prompt (top): the frame. Read first, but a long chat can drift from it.
            • Post-history instructions (bottom): strongest adherence. Put the one or two hard rules the model keeps forgetting here (e.g. “Never write {{user}}’s dialogue”).

            What you can curate

            • Prose & POV — “third-person past-tense literary prose” vs “casual texting, no narration”.
            • Length / pacing — “reply in 2–4 sentences”, “a single line of dialogue”.
            • Dialogue vs action balance — “mostly spoken dialogue, minimal action”.
            • Tone — wry, tender, ominous, comedic, clinical.
            • Anti-patterns — “don’t repeat earlier phrasing”, “don’t end by asking what I want to do”.
            • World on/off — a custom prompt replaces the Chat mode default, so add “no invented setting/scene” yourself if you want assistant behaviour with a custom prompt.

            App trick: formatting drives the voice

            Text-to-speech here speaks only words in "double quotes" and strips *asterisk actions*. So a formatting rule is also a voice control:

            Voice-clean formatting 
            Always put spoken words in "double quotes" and physical actions in *asterisks*. Keep narration brief.

            Gotcha

            Your custom prompt fully replaces the built-in default — which is where the guardrails live (one reply, stay in character, don’t speak for {{user}}, no repetition, never mention being an AI). If you write a bare prompt, bake those in or keep them in Post-history instructions.

            Examples — copy & paste into a card’s System prompt

            Witty assistant (Jarvis-style, no scene) 
            You are {{char}}, in direct conversation with {{user}} — no scene or setting to narrate; never invent surroundings or events. Voice: dry, precise, quietly witty, unflappably competent. Reply in 1–4 sentences, mostly plain speech. Put any spoken words in "quotes". Write only {{char}}'s next reply; never speak or act for {{user}}; don't repeat earlier phrasing; stay in character and never mention being an AI.
            Literary roleplay narrator 
            You are {{char}} in an ongoing story with {{user}}. Write in immersive third-person present tense: vivid but economical prose, "dialogue in quotes", *actions in asterisks*. Advance the moment by ONE concrete beat, 3–6 sentences, then stop. Never narrate, speak, or decide for {{user}}. No repetition; end mid-scene, not on a question.
            Casual texting companion 
            You are {{char}} texting {{user}}. Casual, warm, lowercase, no narration or *actions* — just what you'd actually type. 1–3 short lines. Put everything in "quotes" so it's all spoken. Never text as {{user}}; stay in character.

            Both fields live in the character editor (System prompt / Post-history instructions) and are per-character. Prefer the built-in Chat mode toggle for a quick roleplay↔assistant switch without writing a prompt.
